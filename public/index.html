PANDUAN SISTEM GEEKZPAY REST API

Sistem ini berfungsi untuk mengecek dan mencatat pembayaran QRIS secara otomatis hanya dengan membaca notifikasi handphone Anda sendiri secara langsung.

// LALU BAGAIMANA ALUR KERJA OTOMATISNYA?
  1. Website atau aplikasi Anda membuat kode QRIS Dinamis lengkap dengan Kode Unik di belakangnya (contoh: Rp 10.338).
  2. Pembeli melakukan scan kode QRIS dan membayar pas sesuai angka tersebut.
  3. HP Anda menerima notifikasi SMS atau pop-up dana masuk dari aplikasi bank/e-wallet Anda (seperti DANA, ShopeePay, OVO, dll).
  4. Aplikasi Geekz Forwarder di HP otomatis membaca isi notifikasi teks tersebut, lalu mengirimkannya ke server Anda dalam hitungan detik.
  5. Server website Anda menerima data itu, mencocokkan nominalnya, dan langsung merubah status pembelian menjadi LUNAS.

📚 Contoh Perintah cURL (Bagi Developer Backend)

// A. Membuat Perintah QRIS Dinamis

Salin perintah di bawah ini untuk disuntikkan ke dalam sistem script website backend Anda.

curl -X POST https://restapi.amgeekz.my.id/qris/dynamic \
  -d base_amount=20000 \
  -d unique_code=777 \
  -d payload_static='00020101021126...6304ABCD' \
  -d qr=png
// Contoh Struktur Balasan Sukses dari Server (JSON Response)
{
"base_amount": 20000,
"unique_code": 777,
"total": 20777,
"payload": "00020101021126...",
"qr_png_data_url": "data:image/png;base64,..."
}
// B. Perintah Kirim Notifikasi Pembayaran (Webhook Callback)

Perintah manual ini digunakan apabila Anda ingin mencoba mengetes lemparan mutasi data tanpa melalui aplikasi HP.

curl -X POST 'https://restapi.amgeekz.my.id/webhook/payment?token=USER123' \
  -H 'Content-Type: application/json' \
  -d '{ "message": "Pembayaran Rp 15.250 diterima" }'
□

Info Penting Otomatisasi Terintegrasi:

Apabila aplikasi Android Geekz Forwarder sudah terpasang dan disetting dengan benar di HP Anda, maka Anda tidak perlu lagi mengetikkan kode cURL di atas. Setiap kali ada pembeli yang membayar, notifikasi HP akan langsung terkirim otomatis 100% ke website Anda tanpa henti.

📱 PANDUAN SETTING APLIKASI GEEKZ FORWARDER v2.0

Silakan ikuti 3 tahapan setting sederhana di bawah ini di dalam aplikasi HP Anda agar data dana masuk terkirim dengan lancar dan aman.

📥 UNDUH FILE APLIKASI (.APK) SEKARANG

// Langkah-Langkah Setting di HP Anda

1

HIDUPKAN TOMBOL UTAMA (SERVICE STATE)

Buka aplikasi Geekz Forwarder yang sudah diinstal di HP, aktifkan izin Akses Notifikasi di menu pengaturan Android. Geser saklar tombol utama ke posisi "Enabled (Aktif/Menyala)".

2

PILIH APLIKASI TARGET DI MENU "APP REGISTRY"

Masuk ke menu bernama APP REGISTRY di dalam aplikasi. Beri tanda centang pada nama aplikasi bank atau e-wallet tempat Anda menerima pembayaran (Contoh: DANA, OVO, ShopeePay, GoBiz, atau M-Banking milik Anda). Tujuannya agar aplikasi hanya membaca SMS/notifikasi dari aplikasi keuangan itu saja.

3

MASUKKAN ALAMAT WEBHOOK DI BAGIAN "DATA PIPELINE (SINK)"

Gulir ke bawah ke menu DATA PIPELINE (SINK) untuk mengisi data kemana notifikasi HP tersebut harus dilempar:

// Alamat URL Tujuan Pengiriman Dana:

https://restapi.amgeekz.my.id/webhook/payment?token=USER123

■ PERINGATAN: Gantilah tulisan "USER123" di atas dengan kode token rahasia akun Anda sendiri.
