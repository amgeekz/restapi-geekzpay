Panduan Sistem GeekzPay REST API

Sistem ini berfungsi untuk mengecek dan mencatat pembayaran QRIS secara otomatis hanya dengan membaca notifikasi handphone Anda sendiri secara langsung.

// LALU BAGAIMANA ALUR KERJA OTOMATISNYA?
  1. Website atau aplikasi Anda membuat kode QRIS Dinamis lengkap dengan Kode Unik di belakangnya (contoh: Rp 10.338).
  2. Pembeli melakukan scan kode QRIS dan membayar pas sesuai angka tersebut.
  3. HP Anda menerima notifikasi SMS atau pop-up dana masuk dari aplikasi bank/e-wallet Anda.
  4. Aplikasi Geekz Forwarder di HP otomatis membaca isi notifikasi teks tersebut, lalu mengirimkannya ke server Anda dalam hitungan detik.
  5. Server website Anda menerima data itu, mencocokkan nominalnya, dan langsung merubah status pembelian menjadi LUNAS.
⚠️

📚 Contoh cURL

// A. QRIS Dinamis
curl -X POST https://restapi.amgeekz.my.id/qris/dynamic \
  -d base_amount=20000 \
  -d unique_code=777 \
  -d payload_static='000201...' \
  -d qr=png
// B. Webhook Payment
curl -X POST 'https://restapi.amgeekz.my.id/webhook/payment?token=USER123' \
  -H 'Content-Type: application/json' \
  -d '{ "message": "Pembayaran Rp 15.250" }'
// C. Riwayat Summary
curl -X GET 'https://restapi.amgeekz.my.id/webhook/summary?token=USER123&limit=3'
